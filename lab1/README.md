# Лабораторная работа № 1

## Тема

Запуск OpenBMC с использованием QEMU.

## Выполнено

- запущен образ OpenBMC для машины `romulus-bmc`;
- проверена доступность SSH, HTTPS/Redfish и IPMI;
- проверены состояние BMC и команды управления питанием;
- получены данные FRU через `ipmitool`;
- проверен Redfish API;
- проанализированы журналы и потребление ресурсов.
